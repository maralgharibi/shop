# فروشگاه محصولات آرایشی‌بهداشتی

**تکنولوژی:** Node.js + Express (بک‌اند) · EJS + CSS ساده (فرانت، راست‌چین و ریسپانسیو) · SQLite (دیتابیس فایلی، بدون نیاز به نصب سرور دیتابیس) · فونت وزیرمتن به‌صورت لوکال (بدون وابستگی به CDN خارجی)

## اجرا
نیازمند Node.js نسخه ۱۸ به بالا.

```bash
npm install
npm start
```
سپس باز کنید: http://localhost:3000
پنل مدیریت: http://localhost:3000/admin

**ورود پیش‌فرض:** نام کاربری `admin` و رمز `admin123` — بعد از اولین ورود حتماً از منوی «تغییر رمز» عوضش کنید.

## تنظیمات (اختیاری، با متغیرهای محیطی)
| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `PORT` | پورت سرور | 3000 |
| `SITE_NAME` | نام فروشگاه | مارال |
| `ADMIN_USER` / `ADMIN_PASS` | کاربر مدیر اولیه (فقط در اولین اجرا) | admin / admin123 |
| `SESSION_SECRET` | کلید نشست‌ها — روی سرور واقعی حتماً ست کنید | تصادفی |

مثال: `SITE_NAME="مارال" SESSION_SECRET=یک-رشته-طولانی npm start`

## امکانات
**بخش‌ها و دسته‌بندی‌ها:** پنج بخش آماده (مراقبت پوست، مراقبت مو، آرایشی، عطر و ادکلن، بهداشت شخصی) با ۲۲ دسته‌بندی. از پنل ← «بخش‌ها و دسته‌بندی‌ها» می‌توانید بخش جدید (مثلاً «مادر و کودک») یا دسته جدید بسازید، نام/آیکون/ترتیب را عوض کنید، دسته را به بخش دیگر منتقل کنید یا حذف کنید. همه‌چیز خودکار در منو، صفحه اصلی، فیلترها و فرم محصول ظاهر می‌شود.

**سایت:** صفحه اصلی (بخش‌ها، پیشنهاد ویژه، جدیدترین‌ها)، دسته‌بندی‌ها، جستجو (نام، برند، توضیحات، نوع پوست/مو)، فیلتر قیمت، برند، موجود، تخفیف‌دار، مرتب‌سازی (جدیدترین/ارزان‌ترین/گران‌ترین/بیشترین تخفیف)، صفحه‌بندی، صفحه محصول با گالری عکس، ویژگی‌ها، توضیحات، روش مصرف، ترکیبات و محصولات مشابه.

**پنل مدیریت:** افزودن/ویرایش/حذف محصول، آپلود چند عکس (کشیدن و رها کردن) و انتخاب عکس اصلی، قیمت و قیمت تخفیف‌دار (با نمایش درصد)، موجودی، مخفی/نمایش سریع، مدیریت دسته‌بندی‌ها، تغییر رمز. اعداد فارسی در قیمت پذیرفته می‌شود.

**امنیت:** رمز هش‌شده (bcrypt)، محافظت CSRF، محدودیت تلاش ورود، فقط فایل تصویری تا ۵ مگابایت.

## ساختار
```
server.js        مسیرها و منطق
db.js            ساخت جداول + داده نمونه (اولین اجرا)
views/           قالب‌های صفحات (admin/ = پنل)
public/css|js    استایل و اسکریپت
public/uploads/  عکس‌های آپلودشده
data/shop.db     دیتابیس
```
برای بکاپ کافی است پوشه‌های `data/` و `public/uploads/` را کپی کنید.
برای شروع بدون محصولات نمونه، قبل از اولین اجرا در `db.js` آرایه `samples` را خالی کنید (یا بعداً از پنل حذفشان کنید).
